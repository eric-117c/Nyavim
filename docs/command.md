# command 模块

产品“不用记也能用”的承诺落在这张表上，而不是散落在各处的按键绑定里。

## 契约

- `COMMANDS` 的每一项给出规范名、别名、一句描述、以及绕开面板时的键位。新增能力只需往这张表加一条，四个入口（面板、`: `、F1、提示行）同时获得它。
- `find(word)` 解析用户在 `:` 后输入的名字，大小写不敏感，别名与规范名等价。
- `search(query)` 返回按分数降序、同分按注册顺序排列的匹配项。匹配同时作用于名字与描述，位置分权重：
  - 名字命中给全分，描述命中折半 —— “知道叫什么”永远排在“知道干什么”前面；
  - 连续命中额外加权、首字符命中额外加分，所以 `writ` 排在 `w r i t e` 类散匹配之前。
- `KEYS` 是给 F1 与提示行用的行内动作表，不进 `COMMANDS`：这些动作（motion、算子、模式切换）没有独立命令身份。

## 有意的限制

- 模糊匹配是手写的子序列打分，不做拼音、缩写或前缀树；命令数量在几十条的量级，暴力扫描足够。
